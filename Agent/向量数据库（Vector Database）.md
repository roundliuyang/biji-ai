# 向量数据库（Vector Database）

## 向量数据库概述

常见的向量数据库（Vector Database）主要分两类：**专用向量库** + **基于传统数据库/搜索引擎的向量能力扩展**。

下面是业界最常用的一批：

### 一、专用向量数据库（主流）

#### 1. Pinecone

- **特点**：云原生、托管服务（SaaS）
- 优势：
  - 开箱即用、运维成本低
  - 性能稳定、扩展性强
- **适用**：生产级 RAG、商业AI应用

------

#### 2. Weaviate

- **特点**：开源 + 云服务
- 优势：
  - 支持 GraphQL 查询
  - 内置 hybrid search（向量+关键词）
- **适用**：知识库、搜索增强系统

------

#### 3. Qdrant

- **特点**：Rust 写的高性能向量库
- 优势：
  - 高性能过滤（payload filtering 很强）
  - 部署简单（Docker友好）
- **适用**：推荐系统、检索系统

------

#### 4. Milvus

- **特点**：国内 Zilliz 开源项目
- 优势：
  - 支持超大规模数据（亿级向量）
  - 分布式能力强
- **适用**：大规模 AI 检索系统（工业级）

------

#### 5. Chroma

- **特点**：轻量级向量数据库
- 优势：
  - Python 生态友好
  - 非常适合 RAG demo / 原型
- **适用**：AI 应用快速开发

------

### 二、向量检索库（非数据库）

#### 6. FAISS

- **特点**：Meta 开源库
- 优势：
  - 本地内存检索极快
  - 算法丰富（IVF、HNSW等）
- 缺点：
  - 不支持持久化 / 分布式
- **适用**：算法实验、离线检索

------

### 三、传统数据库扩展

#### 7. Elasticsearch

- **特点**：搜索引擎 + 向量能力（kNN）
- 优势：
  - 传统检索 + 向量混合搜索
  - 生态成熟
- **适用**：日志检索、混合搜索系统

------

#### 8. pgvector

- **特点**：PostgreSQL 插件
- 优势：
  - 直接用 SQL 管理向量
  - 和业务数据强一致
- **适用**：中小规模 RAG 系统

------

### 简单选型建议（很实用）

- **快速做 Demo** → Chroma / FAISS
- **生产级 RAG** → Pinecone / Weaviate / Qdrant
- **超大规模（亿级）** → Milvus
- **已有 ES 系统** → Elasticsearch
- **已有 PostgreSQL** → pgvector
